# Abilene Paradox

По мотивам парадокса Абилина: группа коллективно решает сделать то, чего на самом деле не хотел никто, потому что каждый решил, что этого хотят остальные. Плагин честно вскрывает этот разрыв после голосования.

## Как это работает

1. `/abilene start <вопрос>` — запускает **тайную** фазу (по умолчанию 30 сек): каждый отвечает `/abilene truth yes|no`, ответ не виден никому, включая инициатора.
2. По истечении тайной фазы автоматически начинается **публичная** (по умолчанию 60 сек): `/abilene vote yes|no` — каждый голос сразу транслируется в чат всем (эффект стадности/социального давления).
3. По истечении публичной фазы: объявляется результат публичного голосования, а затем — сравнение с тайным большинством. Если публичный итог разошёлся с тем, чего люди тайно хотели на самом деле — это и есть настоящий парадокс Абилина, засчитывается в счётчик.
4. Ведётся персистентный "Абилинометр" — сколько раз вообще голосовали и сколько раз это был настоящий парадокс.

Одновременно может идти только одно голосование.

## Команды

| Команда | Действие |
|---|---|
| `/abilene start <вопрос>` | Запустить новое голосование |
| `/abilene truth yes\|no` | Тайный ответ (только во время тайной фазы) |
| `/abilene vote yes\|no` | Публичный голос (только во время публичной фазы, виден сразу всем) |
| `/abilene stats` | Показать общий счётчик голосований и парадоксов |

## Конфигурация

| Параметр | По умолчанию | Описание |
|---|---|---|
| Private phase duration (seconds) | 30 | Длительность тайной фазы |
| Public phase duration (seconds) | 60 | Длительность публичной фазы |

## Данные

Персистентно: общее число голосований, общее число настоящих парадоксов. Сама сессия голосования (кто что ответил) не персистится — переживает только выполнение до конца, не переживает рестарт сервера посреди голосования.
